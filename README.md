# Highway Junior School Academic Management System

A web-based academic management and automated assessment system for Highway Junior School.

## Technology Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication

## Main Features

- Learner management
- Teacher management
- Class and stream management
- Subject management
- Curriculum management
- Assessment management
- Automated grading
- Academic reports
- Performance analytics
- Role-based access control
